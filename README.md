# ECHOES_OF_EXILE
O Exiled World transforma o mundo vanilla do Minecraft em um ambiente progressivamente corrompido por portais interdimensionais. O jogador explora, encontra portais, derrota bosses, coleta minérios e artefatos, evolui atributos e desbloqueia novos tiers até derrotar os 20 guardiões e selar o caos.
